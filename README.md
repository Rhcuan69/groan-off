One original one-line dad joke for make.fun's "The One-Liner Groan-Off" bounty ($2 USDC, top 10): I asked my toaster for life advice, and it said to stop pressing me and just pop up when I'm ready. Pure-stdlib Python entry. The program writes the joke to `entry.txt`, deterministically, with no dependencies beyond vanilla Python.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
